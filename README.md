# API REST - CRUD de Usuários

## 📖 Sobre o Projeto

Este projeto consiste no desenvolvimento de uma API REST para gerenciamento de usuários, contemplando as operações básicas de um CRUD (Create, Read, Update e Delete).

O objetivo principal é servir como ambiente de estudos e prática, permitindo a aplicação de conceitos relacionados ao desenvolvimento de APIs utilizando Java e Spring Boot.

## 🎯 Finalidade

Este é um projeto de caráter acadêmico e experimental, criado com o propósito de:

- Praticar desenvolvimento backend com Java e Spring Boot;
- Aplicar conceitos de arquitetura REST;
- Exercitar o uso de banco de dados e persistência de dados;
- Implementar operações CRUD;
- Praticar controle de versão com Git e GitHub;
- Simular fluxos utilizados em ambientes corporativos, incluindo Pull Requests, Code Review e Integração Contínua (CI).

## 🛠️ Tecnologias Utilizadas

- Java 21
- Spring Boot
- Spring Data JPA
- H2 Database
- Maven
- Git
- GitHub Actions

## 🚀 Funcionalidades

- Cadastro de usuários
- Consulta de usuários
- Atualização de usuários
- Remoção de usuários
- Validação automática através de pipeline CI

## ⚠️ Aviso

Este projeto não possui finalidade comercial e foi desenvolvido exclusivamente para fins de aprendizado, experimentação e aprimoramento técnico.
